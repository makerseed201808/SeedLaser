## 任务清单（按顺序做）

### B1 连接清单
- [ ] 连接成为正式数据：每一对连接 = A 边 + B 边 + 类型（指接 a/b、插槽 mortise、槽 slot）+ 长度 + 齿 / 间隙参数；存进项目文件，旧作品迁移（项目文件版本 3）。
- [ ] 右侧新增「连接」面板：列出每一对连接（板件名 · 边 ↔ 板件名 · 边、类型、长度、状态 ✓ / ⚠）；还没配对的卡榫边单独列出。
- [ ] 点一行：画板上两条边高亮并移到画面中间，3D 预览里对应的边也高亮。
- **完成标准**：连接清单和画板上的卡榫边一一对应（测试：建 3 对 + 1 条没配对 → 清单 3 + 1）；旧作品打开后清单正确；点一行高亮。

### B2 建立和修改时自动检查
- [ ] 检查项：两条边长度不一致；齿不互补（A / B 齿位对不上）；齿碰到板角（和相邻边的卡榫冲突）；板厚改了但齿深没改；只有一半的配对（另一条边被删了 / 改成普通边）。
- [ ] 每个问题在连接清单里标 ⚠ 并写原因；能修的给「一键修复」（按另一条边重做、按板厚重做、解除配对）。
- **完成标准**：每类问题一个复现测试（修之前测到 ⚠，修之后 ✓）。

### B3 配对边联动
- [ ] 改一条边的齿数 / 间隙 / 长度（重做卡榫），配对的另一条自动按互补重做；一步撤销。
- **完成标准**：改一边 → 另一边同步；连续改 5 次、撤销 5 次后几何和最初一致（误差 ≤ 0.001 mm）。

### B4 3D 报告到「连接」级别
- [ ] 自动拼装 / 手动摆放后的检查，从「板件穿透 / 没连上」细化到「哪一条连接」：拼不上（没找到配对）、穿透、悬空、错位。
- [ ] 3D 里和连接清单里都显示，点一下在画板上定位。
- **完成标准**：故意造 5 种错误（长度不一、齿数不同、方向反、少一条边、板厚不符），每种都报到对应的连接，不漏报。

### B5 插槽跨板配对
- [ ] 插槽能和另一块板的 A 边配成一对（T 型连接），自动拼装认它；从「已知限制」里去掉。
- **完成标准**：T 型盒子（底板 + 中间隔板插进插槽）自动拼装成功、无穿透；测试覆盖。

### B6 3D 放板 → 二维自动开槽
- [ ] 在 3D 里把一块板放到另一块板上（T 型 / 十字），确认后在二维画板对应位置自动开插槽，并建立连接。
- **完成标准**：放板 → 开槽 → 回 3D 对得上（误差 ≤ 0.01 mm）；一步撤销。
