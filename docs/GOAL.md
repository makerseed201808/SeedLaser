## 任务清单（按顺序做）

### C1 自动排版
- [ ] 二维画板「编辑」菜单和上下文栏加「自动排版」：把所有板件（识别出的外轮廓连同它上面的孔 / 雕刻 / 文字）在材料里自动排好（后端 `freedesign.nest` 已有，补一个接口），间距 = 排版参数；不在板里的图形不动；一步撤销。
- **完成标准**：e2e：放 6 块大小不同的板（有重叠、有超出材料）→ 自动排版 → 全部在材料内、两两不重叠、间距 ≥ 设定值、每块板的孔跟着板走；撤销回原样。

### C2 锁定 / 隐藏图形
- [ ] 选中图形 → 右键菜单 / 变换面板「锁定」：锁定的图形不能选中、移动、删除（点到它时提示「已锁定，右键解锁」）；「全部解锁」。
- [ ] 「隐藏」：隐藏的图形不显示、不选中、仍导出；右侧「图层」卡片里显示隐藏数量和「全部显示」。核对图层卡片的显示 / 隐藏现在是否能用。
- [ ] 锁定 / 隐藏状态存进项目文件（图形的 `locked` / `hidden`），旧作品不受影响。
- **完成标准**：e2e：锁定后拖动 / 框选 / Delete / Ctrl+A 都碰不到它，解锁后恢复；隐藏后画板上看不到、导出里有；保存再打开状态还在。

### C3 尺寸标注
- [ ] 左侧新工具「标注」：点两点（或点一条边）生成一条带箭头和数字的尺寸线，数字随被标注的图形变化（标注记住它量的是哪个图形的哪两个点）；拖动标注可以改引出距离。
- [ ] 标注是独立的一类图形（`mode: 'dim'`），默认不导出；「文件 → 导出」里可选「把标注一起导出（描线）」。
- **完成标准**：e2e：标一条边 → 数字 = 边长；改图形宽度 → 数字跟着变；默认导出的 SVG 里没有标注，勾选后有且在描线层。

### C4 图库
- [ ] 左侧新工具「图库」：右侧面板分「内置」「我的」两组，缩略图网格，点一下放到画板中心（或拖到画板）。
- [ ] 内置 30 个常用件：标准孔（M3 / M4 / M5 通孔、沉孔）、舵机（SG90、MG996）安装孔、Micro:bit / Arduino UNO / ESP32 安装孔、常用轴孔（3 / 4 / 5 / 6 / 8 mm）、LED 5 mm 孔、按钮 12 mm 孔、USB 开口、散热孔阵、把手孔、挂孔、常用装饰（圆角板、星、心、箭头、齿轮轮廓）。尺寸写在名字里，数据放 `web/library/*.json`，尺寸来自元件数据手册（在文件里注明出处；查不到的标「未核对」）。
- [ ] 「保存到我的图库」：选中图形 → 起名 → 存到 `~/Documents/SeedLaser/图库/`（每个一个 `.seedlaser-shape` 文件，内容是 JSON）；可删除。
- **完成标准**：e2e：放一个内置件 → 尺寸正确；保存一个自定义件 → 重开后还在、能放、能删。

### C5 一键造物（参考 LaserMaker）
- [ ] 左侧新工具「造物」，右侧面板四个入口，参数少、有示意图，点「生成」直接放到画板上（变成普通板件，可以继续改）：
  - **直角盒子**：内 / 外尺寸、长宽高、板厚、有没有盖、卡榫齿宽 → 生成全部板件并自动配对（复用快速建模的 ABox / ClosedBox，参数映射好，不让学生面对 Boxes.py 的参数表）。
  - **圆角盒子**：同上 + 圆角半径（复用 RoundedBox）。
  - **模数齿轮**：模数、齿数、压力角 20°、轴孔直径、可选减重孔 → 标准渐开线齿轮（算法按 ISO 53 / 机械手册的渐开线公式，代码里注明）；两个齿轮按中心距摆好。
  - **徽章 / 印章**：形状（圆 / 方 / 盾）、直径、边框、文字（可弧形）、是否镜像（印章要镜像）。
- **完成标准**：e2e：每种生成一次，板件数 / 尺寸正确；盒子生成后连接清单全部 ✓、自动拼装无穿透；齿轮齿数和模数反推一致（分度圆直径 = 模数 × 齿数，误差 ≤ 0.01 mm）。

### C6 二维码 / 条形码
- [ ] 文字工具旁加「二维码」：输入内容 → 生成 QR（矢量方块，雕刻层）；条形码 Code 128。批量名牌可以选「加二维码」。
- **完成标准**：生成的 QR 用 Python 的解码库读回来内容一致（后端测试）。

### C7 打断 / 橡皮擦
- [ ] 修剪工具加两种方式（右侧选）：**打断**（点一下把线在这一点断成两段）、**橡皮擦**（拖过去擦掉经过的一段，长度 = 擦除宽度）。
- **完成标准**：e2e：打断后节点数 / 图形数正确；擦一段后剩两段，长度之和 = 原长 − 擦除长度（≤ 0.1 mm）。

### C8 改卡槽宽度（导入的图纸）
- [ ] 变换面板加「改槽宽」：自动找出选中图形里宽度 ≈ 某个值（默认旧板厚）的矩形槽 / 缺口，改成新板厚（居中加减），预览标出会改哪些。
- **完成标准**：e2e：导入一个 3 mm 槽的 SVG → 改成 4 mm → 所有槽 4 mm，别的边不动。

### C9 小项合并
- [ ] 文字样式：粗体、斜体、竖排（用字体的粗体 / 斜体字形，没有就合成）。
- [ ] 上下文栏：按倍率缩放（%）、移动指定距离（ΔX / ΔY）。
- [ ] 圆角支持负半径（挖圆缺口）。
- [ ] 「连接线段」：选中几条首尾相接的开放线 → 接成一条。
- **完成标准**：每项一个 e2e 断言。
