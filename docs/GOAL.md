### C3 尺寸标注
- [x] 左侧新工具「标注」（D）：点两点（或点一条边）生成一条带箭头和数字的尺寸线，数字随被标注的图形变化（标注记住它量的是哪个图形的哪两个点）；拖动标注可以改引出距离。数字按屏幕像素定大小（缩小视图也看得清），放在尺寸线外侧。
- [x] 标注是独立的一类图形（`mode: 'dim'`），默认不导出；「文件 → 导出」里可选「把标注一起导出（描线）」（有标注时导出框里出现这个勾选；数字导出为文字）。标注归到它量的板上，不算「不在板里」；不计入「图形 N 个」。
- **完成标准**：e2e：标一条边 → 数字 = 边长；改图形宽度 → 数字跟着变；默认导出的 SVG 里没有标注，勾选后有且在描线层。
- **证据**：`tests/e2e/dim1.py`（点边标注 = 100、点两节点 = 两点距离、改宽度 100 → 130 数字跟着变并可撤销、拖动标注改引出距离 15 → 25 且引出线仍从边开始、不算不在板里、默认导出无标注 / 勾选后描线层 ≥ 5 条 + 数字文字、保存再打开仍引用图形）；全部测试通过（50 个 e2e + py + js）。

### C5 一键造物（参考 LaserMaker）
- [x] 左侧新工具「造物」，右侧面板四个入口，参数少、有示意图，点「生成」直接放到画板上（变成普通板件，可以继续改）：
  - **直角盒子**：内 / 外尺寸、长宽高、板厚、有没有盖、卡榫齿宽 → 生成全部板件并自动配对。**和原计划不同**：没有复用 ABox / ClosedBox——它们的齿是直接画进轮廓的，二维画板认不出是卡榫，连接清单是空的、也不能按卡榫自动拼装；改成用画板自己的卡榫生成（每块板 = 内部尺寸的矩形，12 条边配成 12 对指接 A / B），所以连接清单、检查、3D 报告、自动拼装都能用。已知：盒子 8 个外角各缺一个板厚大小的小方块（三块板相交处没有板），不影响强度。
  - **圆角盒子**：同上 + 圆角半径 + 顶部（封闭 / 开口环 / 带盖），复用 RoundedBox（侧壁是一整条活铰链板）。弯曲的板没法当平板摆，3D 里不拼装。
  - **模数齿轮**：模数、齿数、压力角 20°、轴孔直径、可选减重孔 → 标准渐开线齿轮（ISO 53 基本齿廓，公式写在 `SketchEditor.gearPoints` 的注释里）；勾「再配一个齿轮」时两个齿轮按中心距 m(z1+z2)/2 摆好、齿对齿槽。
  - **徽章 / 印章**：形状（圆 / 方 / 盾）、大小、边框（描线）、文字（可弧形，雕刻）、镜像（印章要镜像）。
- [x] 顺带修复：「按卡榫自动拼装」先找一组让所有配对同时对上的摆法（闭环：盒子四面墙互相约束；原来逐块贪心，第一面墙可能放反，导致 3 对连接「没拼在一起」），找不到才退回逐块贪心；整组朝下时翻正。快速建模「放进设计」漏了开放的切割线（活铰链切缝），已补上。
- **完成标准**：e2e：每种生成一次，板件数 / 尺寸正确；盒子生成后连接清单全部 ✓、自动拼装无穿透；齿轮齿数和模数反推一致（分度圆直径 = 模数 × 齿数，误差 ≤ 0.01 mm）。
- **证据**：`tests/e2e/make1.py`（有盖直角盒子 6 块 12 对、清单全部 ✓、自动拼装 6 块无穿透且 12 对 3D 全部 ✓、盒子立着；外部尺寸无盖 5 块 8 对、内部 = 外部 − 板厚；圆角盒子 3 块、侧壁带活铰链切缝；齿轮 m=2 20 + 12 齿：齿数、齿顶圆反推模数、分度圆 ≤ 0.01、中心距 32；徽章外形 50 mm + 描线边框 + 雕刻文字，印章镜像后文字左右翻转）；`tests/js/gear.test.mjs`（4 组模数 / 齿数：齿顶圆、齿根圆、分度圆、分度圆齿厚 = πm/2、对称、齿数）；全部测试通过。

### C6 二维码 / 条形码
- [x] 文字工具右侧切「文字 / 二维码 / 条形码」：输入内容、边长（条形码：宽度、条高）→ 单击放置，生成矢量轮廓（相邻黑块合并成多边形，雕刻层）；选中后可以改内容 / 尺寸「重新生成」（位置不变）；内容存在项目文件里。QR 用 qrcode 库（Boxes.py 自带），Code 128 自己编码（偶数位纯数字用 C 集，其余 B 集；码表按 ISO/IEC 15417），中文不能做条形码时提示。批量名牌可以勾「右边加二维码」，内容模板里的 {名字} 换成每一行的名字。
- **完成标准**：生成的 QR 用 Python 的解码库读回来内容一致（后端测试）。
- **证据**：`tests/py/test_codes.py`（6 个：网址 / 中文 / 单字 QR、字母 / 纯数字 C 集 / 带空格符号的 Code 128，矢量轮廓栅格化后用 zxing-cpp 解码，内容和码制一致；没装 zxing-cpp 时只跑编码检查并提示）；`tests/e2e/code1.py`（放置位置 / 尺寸 / 雕刻层、重新生成可撤销、中文条形码报错、保存再打开、批量名牌加二维码）；全部测试通过。打包清单 SeedLaser.spec 补上 codes2d、dxfout。

### C7 打断 / 橡皮擦
- [x] 修剪工具右侧选「修剪 / 打断 / 橡皮擦」：**打断**（单击把线断开，断点吸附网格 / 端点；开放的线变两个图形，闭合图形变开放）、**橡皮擦**（单击或拖过，每处擦掉「擦除宽度」那么长；拖动整段算一步撤销；只擦真的点在线上的地方）。
- **完成标准**：e2e：打断后节点数 / 图形数正确；擦一段后剩两段，长度之和 = 原长 − 擦除长度（≤ 0.1 mm）。
- **证据**：`tests/e2e/erase1.py`（打断 100 mm 线 → 2 个图形各 2 节点、40 + 60、一步撤销；打断矩形 → 开放 6 节点、周长 240；橡皮擦宽 2 点一下 → 两段和 98（≤ 0.1）；拖过 20 mm → 擦掉约 22、一步撤销；擦矩形 → 开放、周长 238；修剪照常）；全部测试通过。

## 自动运行规则（每次运行都必须遵守）

1. 开始前先读 `CLAUDE.md`、本文件、`CHANGELOG.md` 的「未发布」一节。
2. 一次只做一条任务；做完才能做下一条。
3. 界面只加清单里写的；风格和现有一致。清单外的写进「待你决定」，然后跳过。
4. 每个功能先写测试，再做；提交前跑全部测试（`tests/e2e/run.sh`、`tests/py`、`tests/js`），全部通过才提交。
5. 提交信息写清楚改了什么和证据；在本文件对应的任务上打勾，写上证据和日期；`CHANGELOG.md` 的「未发布」加一行。
6. 改脚本后检查可执行权限。
7. 结束时更新「最近一次运行」：做了什么、哪些还没验证。缺数据就写「未验证」，不推测。
