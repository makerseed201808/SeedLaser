# SeedBoxes 路线图与开发要求

> 本文件是给开发者（含 Claude Code）的「做什么、怎么证明做对了」。架构细节见 CLAUDE.md，历程见 DEVELOPMENT.md。
> 最近更新：2026-11-07（分支 feat/3d-model，未推送）

## 产品定位（已与用户确认）
1. 二维编辑器 = 学生的二维绘图工具，只导出图纸给激光机，不做机器控制。
2. 保留传统基础二维编辑，锻炼绘图基本功（绘图部分对标 LightBurn / 雷宇 LaserMaker）。
3. 3D 的价值：在切割前看到二维图纸会拼成什么、错在哪里——观察构造、核查装配、反向推动修改二维。
4. 创新点：二维 → 三维之间的「连接（榫卯）与定位」。
- 路线：二维为主、3D 校验、3D 的少量操作写回二维（改尺寸、放隔板自动开槽、修复建议）；「连接」做成正式数据（A 边 + B 边 + 类型 + 夹角 + 参数），齿形永远落在二维；边对边在 2D 建立，T 型 / 十字在 3D 放置；手画 / 导入的齿自动识别后确认。
- **深入而不扩大**：优先把现有功能做可靠、可验证，不加新的大功能面。

## 已完成（摘要）
- 3D：36 个生成器自动装配、干涉检查、SketchForge 装配编辑器（磁吸、一键装配）。
- 二维：全套绘图 / 编辑工具（见 CLAUDE.md），布尔单选语义（差集 = 刀；交集 = 只留重叠；并集 = 合并；悬停示意图），重叠交叉时弹窗选择处理方式，Ctrl 画正圆，导入 / 描摹，阵列，对齐，标尺参考线，尺寸标注，连接点，新手引导。
- 连接：卡榫 / 插槽工具，跨板配对（pair id），按配对自动拼装。
- 自由设计：先进二维画板，自动识别板件，排版位置与装配位置互相独立，导出所见即所切。

## 已修 BUG（本轮）
测量读数被标尺遮挡；工具栏压扁；拖动时板面不跟随；改文字点画布不生效；文字笔画自重叠误标红；画板标签残留；改形状导致装配错位；交叉重叠处显示为空（现：完全在内才是孔）；3D 编辑器缺板（打开时校验补回，编辑器删板不再改「不使用」）。

## 计划
### A 线：二维基本功（打磨）
1. 按学生操作顺序逐个工具系统测试，问题清单写复现步骤 + 截图，按「严重度 × 频率」排序。
2. 几何边界情况：自相交、零长度段、重合节点、似闭合实未闭合、曲线展平精度。
3. 性能：200 个图形拖动流畅。
4. 术语表统一（切割 / 雕刻 / 描线 / 卡榫 / 插槽 / 连接点 …）。
### B 线：连接与定位（创新）
1. 连接数据化 + 建立时检查（边长一致、齿互补、板角冲突、间隙按材料）。
2. 3D 按连接自动定位，报告「哪条连接出问题」。
3. 3D 放板 → 二维自动开槽（T 型、十字）；二维 ↔ 3D 互相高亮。
4. 自动识别手画 / 导入的齿（参考 HPI Assembler3 / AutoAssembler 论文原文）。
5. 板厚联动、卡扣测试条、配对边尺寸联动。
### 已知限制
插槽不能跨板配对；异或需选 2 个；只支持 90° 连接。暂不做：加工时间估算。

## 开发要求（每次都要做，不用用户提）
**原始材料优先**
- 物理数据以学校激光机切出的测试样为准（切缝、实测板厚、配合松紧，卡尺读数 + 照片，由用户提供）；拿到前所有公差标「暂定」。
- 问题来源优先：学生真实图纸、失败成品照片、操作录屏。
- 格式 / 算法依据一手资料：SVG 1.1 规范、Autodesk DXF Reference、Boxes.py 卡榫源码、paper.js 与 shapely/GEOS 的布尔规则；引用注明出处。
- 竞品写具体操作和结果；研究读论文原文。

**主动做**
- 每修一个 BUG，补一个能复现它的自动测试。
- 维护不变量测试：2D ↔ 3D 往返位置不变；布尔面积守恒；导出路径闭合、无重复线；paper.js 与 shapely 结果一致。
- 导出：单位 / 尺寸 / 颜色图层可验证；内孔先切、外轮廓后切。
- 项目文件版本号 + 迁移测试（旧作品必须能打开）。

**方法与工具**
- pytest + shapely（后端几何）、node + paper.js（前端几何）、Playwright 端到端（tests/e2e/）、导出文件 golden 比对、随机图形压力测试布尔、ezdxf 校验 DXF。
- 实物测试样生成器：切缝梳、配合阶梯 0.00–0.30 mm。
- 3D 干涉按公差量化为：穿透 / 贴合 / 有缝。
- 可用性：3 个学生任务（如 15 分钟画出带卡榫的笔筒），记录完成率、用时、出错点、SUS。

**验收（不靠主观判断）**
1. 自动测试全部通过，报告数量和新增项。
2. 导出文件在 LaserMaker / LightBurn 中尺寸误差 ≤ 0.1 mm、图层正确、路径闭合、无重复线（用户核对）。
3. 用实测公差切出的卡榫手按可入、缝隙 ≤ 0.2 mm、拼好不晃（用户提供照片 + 读数）。
4. 3D 校验与实物对照，统计误报 / 漏报，目标不漏报。
5. 学生任务完成率 / 用时达到事先约定的目标。

**工作方式**
- 每阶段开始先列验收证据清单，标明哪些能自动验证、哪些需用户提供实物 / 学生数据。
- 每次改动报告：改了什么、证据（测试名或截图）、哪些仍未验证。缺数据就写「未验证」，不推测。
- commit 信息写清证据；push 前先经用户确认。
